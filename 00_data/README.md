# Data

- `participants.csv`: participant metadata and SAM ratings for 148 children.
- `raw_data/`: raw BrainVision recordings; includes `sub-001`. Filename IDs must match the participant table.
- `events/Movies_rating_by_RA.csv`: movie-intensity ratings used by the analyses.

Open [run_sample_characteristics.ipynb](run_sample_characteristics.ipynb), select
**Python (dbh)** and run the cells in order. Table S1 and the sex-ratio test are
displayed in the notebook and saved to the repository’s [results/SI/](../results/SI/).

See the [root README](../README.md) for environment setup and input requirements.
